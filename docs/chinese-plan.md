# 跳跳小老師 → 多科目：加入國文（規劃）

> 目標：同一個 app 裡有「數學」和「國文」兩科，共用跳跳、點心、等級。國文的重點是 **大量練習題 + 用 Apple Pencil 作答**，先從她最弱的 **改錯字** 和 **字音字義** 開始。
> 建議做法：數學 Phase 7 完成後再開始。把本文件放進 repo（`docs/chinese-plan.md`），確認後再併入 CLAUDE.md。

---

## 1. 整體架構

- **首頁**：上方是跳跳卡片（不變），下面兩張科目卡片：「數學」「國文」。每科顯示今天練了幾題。
- **共用**：跳跳、點心、等級、配件、備份／還原、PIN、設定頁。兩科答對都算進跳跳的題數。
- **路由**：數學維持現有頁面（之後可整理成 `/math/...`，舊網址要自動轉址）；國文用 `/chinese/...`。
- **統計**：設定頁的「學習紀錄」分科目顯示。

## 2. 國文題型（依優先順序）

| # | 題型 | 例子 | 作答方式 |
|---|---|---|---|
| 1 | **改錯字** | 「他做事總是迫不急待。」找出錯字並改正 | 用筆**點**錯的字 → 在方格裡**寫**正確的字 |
| 2 | **字音（選出讀音）** | 「行」在「銀行」的讀音？(A) ㄒㄧㄥˊ (B) ㄏㄤˊ | 點選選項 |
| 3 | **字音（讀音相同／不同）** | 下列「 」中的字，哪一組讀音相同？ | 點選選項 |
| 4 | **國字注音** | 寫出「酗」酒的注音 | 點注音鍵盤（Pencil 寫注音辨識不可靠） |
| 5 | **注音寫國字** | 再接再「ㄌㄧˋ」 | 在方格裡**寫**國字 |
| 6 | **字義** | 「走馬看花」的「走」意思是？ | 點選選項 |
| 7 | **字義相同／不同** | 哪一組「 」中的字意思相同？ | 點選選項 |
| 8 | 成語／詞語運用（之後再加） | 下列成語使用何者正確？ | 點選選項 |

每題答完都有**一句話的解釋**，講「為什麼」，例如：「『厲』是磨利的意思，再接再厲＝一直磨練自己，不是『勵』（鼓勵）。」

---

## 3. Apple Pencil 作答

- **寫國字（題型 1、5）**：用 iPadOS 內建的 **隨手寫（Scribble）**。網頁上的文字輸入框可以直接用 Apple Pencil 寫中文，iPad 會自動轉成文字，不需要另外做手寫辨識。
  - 輸入框做成大大的方格（像作業簿的格子），提示「用筆寫在格子裡」。
  - 轉出的字跟答案比對（完全相同才算對）。
  - **一定要在她的 iPad 上先測試**：設定 → Apple Pencil → 隨手寫要打開，並確認有繁體中文。
- **點選（題型 1 找錯字、2、3、6、7）**：題目句子每個字都可以點，選項是大按鈕（≥ 56px）。
- **注音（題型 4）**：自己做一個注音鍵盤（聲母、韻母、聲調），用點的。
- **練字（加分功能）**：答錯的字可以在大格子裡用筆描寫 2～3 次（canvas，不批改，只是練習），寫完跳跳鼓勵。

## 4. 題庫：正確性最重要

AI 在**多音字、注音、教育部審訂讀音**最容易出錯，而且錯得很有自信。所以：

1. **題庫是 repo 裡的 JSON 檔**，不是即時用 AI 出題。
   - `content/chinese/<課次>.json`，每題：`{ id, type, lesson, prompt, options?, answer, explanation, source, verified }`
2. **題目來源**：
   - **她的課本**：拍下每課的「生字、詞語、注釋」頁 → 轉成文字 → 用這些字詞出題（康軒國一，跟學校進度一致）。
   - **她的考卷**：拍下老師改過的考卷 → 擷取她錯的題目，**答案以老師的訂正為準**。
3. **產題流程（由你在 Claude Code 裡跑，不在 iPad 上即時跑）**：
   - 腳本用 Claude 依課次大量產生題目草稿
   - **自動檢查**：讀音和字義要跟教育部辭典資料比對（可下載教育部《重編國語辭典修訂本》資料，使用前確認授權條款；開源的「萌典」就是用這份資料做的）。對不上的題目標記為「待確認」
   - **大人審核頁**（只有加 `?admin=1` 才看得到）：逐題看草稿，按「通過／修改／刪除」，通過的才 `verified: true`
   - 只有 `verified: true` 的題目會出現在她的練習裡
4. **好處**：不會有錯的題目、不會碰到 Netlify 10 秒逾時、API 費用很低（她練習時完全不用呼叫 AI）。

## 5. 練習方式

- **每日練習（預設）**：一次 10 題、約 5～10 分鐘。混合三種題目：
  - 最近答錯的（優先）
  - 到期要複習的
  - 新題目（目前上到的課次）
- **間隔複習（Leitner 盒子）**：答對 → 升一盒，下次隔更久再出（1 天、3 天、7 天、14 天…）；答錯 → 回到第一盒，明天再出。
- **錯題本**：她錯過的題目集中在一頁，可以只練錯題。
- **選課次／題型**：考前可以只練某幾課、某一種題型（例如只練改錯字）。
- **獎勵**：每完成一組每日練習 → 跳跳慶祝 + 點心；一組全對 → 點心 +2。單題答對不跳慶祝畫面（題目多，會太吵），只有小小的跳跳點頭動畫。

## 5.5 收藏與列印（兩科共用）

**收藏（⭐）**
- 每一題右上角都有星星按鈕，點一下收藏、再點一下取消。
- 國文：練習中、解釋畫面、錯題本都可以收藏。
- 數學：原題和練習題都可以收藏（在答對畫面和歷史紀錄裡）。
- 「我的收藏」頁：分「數學／國文」兩個分頁，可以依題型、課次、日期篩選，也可以直接從收藏開始練習。
- 收藏存在 IndexedDB，**加進備份碼**，換 iPad 或清掉資料也能還原。

**列印**
- 在「我的收藏」勾選題目（或「全選」）→「列印」→ 進到列印預覽頁 `/print`。
- 列印選項：
  - 「附答案」：答案和解釋放在**最後一頁**（答案卷），題目頁不會出現答案，方便她先寫再對答案
  - 「留作答空間」：數學題下面留空白、國文改錯字和注音寫國字留方格
  - 「數學附原始照片」：縮圖印在題目旁（預設關閉，省墨水）
- 版面：A4 直式、黑白也清楚（不靠顏色區分）、題目不會被切在兩頁中間、頁首印「數學小老師・我的收藏・日期」、頁尾頁碼。
- 數學式用 KaTeX 正常印出；注音用直排小字或括號標示。
- iPad 上按「列印」會呼叫 `window.print()` → 可以用 AirPrint 直接印，或在列印畫面用兩指放大存成 PDF。
- 列印用專用的 print CSS（`@media print`），隱藏按鈕、跳跳動畫和背景色。

## 7. 建議的 Phase

| Phase | 內容 |
|---|---|
| **C1** | 多科目架構：首頁科目卡片、路由整理（舊網址轉址）、共用跳跳與點心、分科統計 |
| **C2** | 題庫格式 + 練習引擎（選擇題類型 2、3、6、7）+ 每日練習 + 解釋 |
| **C3** | Apple Pencil 題型：改錯字（點字 + 寫字）、注音寫國字、國字注音鍵盤、練字格 |
| **C4** | 間隔複習 + 錯題本 + 選課次／題型練習 |
| **C5** | 產題流程：課本照片 → 產題腳本 → 教育部辭典自動檢查 → 大人審核頁 |
| **C6** | 從考卷照片匯入她的錯題（答案以老師訂正為準） |
| **C7** | 收藏（兩科）+「我的收藏」頁 + 列印預覽與 print CSS（附答案卷、作答空間） |

收藏按鈕本身很小，可以在 C2 就先加上（只存資料），C7 再做收藏頁和列印。

先用 **C5 的手動版**起步：在 C2 之前，先手動準備一課的題目（約 30 題），讓 C2～C4 有真實題目可以測。
